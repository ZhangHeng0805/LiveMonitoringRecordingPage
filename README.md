# LiveMonitoringRecordingPage
[LiveMonitoringRecording](https://github.com/ZhangHeng0805/LiveMonitoringRecording)项目的监控展示界面

[在线演示](https://zhangheng0805.github.io/LiveMonitoringRecordingPage/)

> 需要配合参数来设置后端接口地址，实现前端页面的数据展示和功能。
> * 参数url: 后端接口地址，建议使用URLcode或Base64编码，编码传值异常，例：```https://zhangheng0805.github.io/LiveMonitoringRecordingPage/?url=https://1eeb1fea.r15.vip.cpolar.cn/```
> * 参数redirect：重定向配置文件，通过JSON配置文件读取，后端接口等配置信息，例：```https://zhangheng0805.github.io/LiveMonitoringRecordingPage/?redirect=redirect/json/config.json```，配合[LiveMonitoringRecording](https://github.com/ZhangHeng0805/LiveMonitoringRecording)项目中的cpolar工具使用实现配置文件内容自动更新，可以实时获取最新的后端接口地址等配置信息
